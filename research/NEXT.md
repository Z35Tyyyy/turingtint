# Next iterations

The prototype has working source comparison, two evaluated local classifiers and an evidence loop. Neither classifier is validated for release. Read [phase 2 results](phase2-results.md) and preserve its observed sets as diagnostics. Keep these tasks linked to the open gates in `evaluation/protocol.json`.

1. **Expand target-domain evidence.** AIDE's actual public artifact has 1375 human essays but only 3 AI essays. Investigate publisher-linked ASAP/ASAP2 for multiple legacy assignment prompts; verify actual download rights/counts and document/author lineage. Rights to Nigerian repository texts remain unresolved. No paid services or automatic terms acceptance.
2. **Create a bounded contemporary AI development counterpart.** Use openly licensed local generators with recorded model hashes, source/prompt links, seeds and generation parameters. Match assignments and length rather than confounding corpus identity with label. Preserve human labels from actual source evidence. Reserve whole prompt families and a generator before scoring; keep related variants together.
3. **Improve the model on development evidence.** Compare target-domain training and the documented MAGE preprocessing/logit recipe. Existing raw-text softmax thresholds are not probability calibration. Freeze choices before new test scoring. Existing calibration, subgroup metrics, confidence bounds and recomputing checks are implemented; retain their independence/sample-size/unseen-generator blocks until the required evidence exists. Never reuse the now-observed AIDE/HC3 diagnostics as an untouched final test.
4. **Benchmark retrieval separately.** Expand beyond the 12-abstract engineering seed; freeze exact/light-edit/quotation/common-phrase/same-topic/source-absent cases. Report corpus coverage separately from alignment correctness. Unit fixtures and the demo passage are not the accuracy test.
5. **Study mixed text and localization.** Find rights-audited workflow labels or use honestly labeled synthetic operations. Real human post-editing remains an evidence gap; do not substitute AI impersonation.
6. **Improve suggestions after evidence exists.** Preserve factual details and attribution; never claim that lowering a model score proves human authorship.

For every iteration: record hypothesis → implement bounded change → test → independent review → fix → rerun → retain unresolved gaps. The current journal remains `training/decisions.jsonl`; `.iteration/` contains local run history and issue states.
